# EZTABLE 簡單桌 餐廳訂位

> 本功能為個人 fork 新增，僅供自己訂位使用。EZTABLE 服務條款禁止轉售餐券圖利。

## 程式會做什麼

1. 開啟設定的餐廳頁，例如 `https://tw.eztable.com/restaurant/1730`
2. 選擇用餐人數
3. 依日期關鍵字選日期（本月沒有符合的日期時，最多往後翻 2 個月）
4. 依時段關鍵字選時段
5. 按「填寫付款資訊」進入訂位表單
6. 表單頁要求登入時播放提示音並等待；進入付款頁時播放提示音並發送 Discord／Telegram 通知

**登入與付款一律由你手動完成，程式不會填寫信用卡資料，也不會送出付款。**

人數已滿、還沒開放訂位，或找不到符合的日期／時段時，程式會依「自動刷新頁面間隔(秒)」重新整理頁面
（設為 0 則不重新整理）。

## 設定方式

| 設定介面欄位 | 用途 | 範例 |
|------|------|------|
| 網址 | 餐廳頁網址 | `https://tw.eztable.com/restaurant/17914` |
| 張數 | 用餐人數（大人） | `2` |
| 日期關鍵字 | 想訂的日期，可填多個（依序嘗試） | `"2026-11-28","11/29","週六"` |
| 區域關鍵字 | 想訂的時段 | `"18:00","18:30"`、`"18"`（18 點的任一時段）、`"11:30-12:30"`（區間） |
| 日期／區域關鍵字下方的「啟用」遞補 | 沒有符合的日期或時段時，改選任一可訂的 | 預設關閉 |
| 刷新在指定時間 | 餐廳固定時間開放訂位時，到時間才開始動作 | 例如島語「週六 11:00 開賣」 |

日期可寫成 `2026-11-28`、`2026/11/28`、`11/28`、`11-28`、`11月28日`，或星期 `週六`／`星期六`。
同一組引號內用空白分隔代表「同時符合」，例如 `"週六 11/28"`。

## 建議流程

1. 開賣前先用程式開啟的 Chrome 登入 EZTABLE（LINE 或簡訊驗證），登入狀態會保留
2. 設定好開賣時間，讓程式在開賣當下開始選位
3. 聽到提示音後回到瀏覽器，確認方案、填寫資料並付款
